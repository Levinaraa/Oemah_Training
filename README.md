# 🎓 Oemah Training

Platform informasi pelatihan teknologi informasi (IT) berbasis React + Vite. Menyediakan informasi program pelatihan, profil trainer, galeri kegiatan, dan layanan konsultasi.

## 📌 Fitur Utama

- **Halaman Home** - Landing page dengan hero section, materi pelatihan, dan testimonial.
- **Halaman Training** - Daftar program pelatihan dengan filter dan sidebar kalender.
- **Halaman Trainer** - Profil para instruktur ahli di bidang IT.
- **Halaman Foto** - Dokumentasi kegiatan workshop dan pelatihan.
- **Halaman Kontak** - Form inquiry dan informasi kontak.
- **Halaman Tentang Kami** - Profil dan visi misi Oemah Training.
- **Navigasi & Footer** - Responsif dengan integrasi React Context.

## 🛠️ Tech Stack

- **React 19** - Library UI
- **Vite 8** - Build tool super cepat
- **React Context API** - State management global
- **Lucide React** - Icon library
- **FontAwesome** - Icon tambahan
